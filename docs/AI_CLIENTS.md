# Compatible AI clients

The workspace targets agents that can read and edit local project files.

| Client | Type | Official download / setup | Repository adapter |
| --- | --- | --- | --- |
| ChatGPT Desktop + Codex | Desktop / agent | https://chatgpt.com/download/ | Native `AGENTS.md` |
| Claude Desktop / Claude Code | Desktop / CLI | https://claude.com/download | `CLAUDE.md` -> `AGENTS.md` |
| Gemini CLI | CLI | https://github.com/google-gemini/gemini-cli | `GEMINI.md` -> `AGENTS.md` |
| Cursor | Editor / agent | https://cursor.com/download | `.cursor/rules/` -> `AGENTS.md` |
| Ollama | Local model runtime | https://ollama.com/download | Pair with a compatible agent for full automation |

See [INSTALLATION.md](INSTALLATION.md) for the complete setup flow.
