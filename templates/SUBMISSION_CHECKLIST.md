# Submission checklist

- [ ] Correct organization and role confirmed.
- [ ] Destination URL confirmed.
- [ ] Job description reviewed in full when available.
- [ ] Essential requirements mapped to verified evidence.
- [ ] No unsupported claims added.
- [ ] CV/resume file reviewed.
- [ ] Cover letter reviewed if applicable.
- [ ] Form answers reviewed.
- [ ] Sensitive fields reviewed by the user.
- [ ] Uncertainties resolved or explicitly accepted by the user.
- [ ] User explicitly authorized this specific final submission.

If the last checkbox is not complete, stop before submission.
